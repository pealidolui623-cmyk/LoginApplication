# AI Chatbot App

## About the Project
This is an AI Chatbot Android application developed using Android Studio and Kotlin. It allows users to send messages and receive AI-generated responses through the Groq API.

## Technologies Used
- Android Studio
- Kotlin
- XML
- Groq API

## Features
- User can type and send messages.
- AI generates responses to user messages.
- Chat messages are displayed in a chat interface.

## How to Run
1. Download or clone this repository.
2. Open the project in Android Studio.
3. Configure your Groq API key securely.
4. Run the application on an Android device or emulator.
